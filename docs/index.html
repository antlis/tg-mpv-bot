A self-hosted Telegram bot that turns any always-on Linux box plugged into a TV into a media center you control from the couch — or the other side of the world. No cloud, no AI, no port forwarding, no smart-TV apps: the bot talks to mpv's IPC socket directly and only ever makes outbound connections.

What it does

📋 Browse your libraryCategories → playlists as inline buttons, full-text search, episode picker, chapters.
🔗 Stream any linkSend a YouTube / SoundCloud / any yt-dlp URL — it plays on the TV, subtitles included.
🔎 Search YouTube from chat/mpv_yt lofi beats — top results with thumbnails, tap to play.
📨 Forward video filesAny Telegram video plays on the TV — up to 2 GB with a local Bot API server.
🎛 Full transport controlOne now-playing panel: pause, seek, %-jump, volume, speed, audio & subtitle tracks.
▶ Continue watchingHistory with one-tap replay; playlists and streams resume where you left off.
🔔 Knows when you're done"⏭ Now playing: 6/12" on episode change, "✅ Finished" at the end. Sleep timer included.
🩺 Runs itselfAuto-updating yt-dlp, playlist doctor/repair, disk GC, one-screen health check.

Install

# needs mpv + uv; token from @BotFather
git clone https://github.com/antlis/tg-mpv-bot && cd tg-mpv-bot
uv sync
cp .env.example .env        # set BOT_TOKEN and ALLOWED_USERS
set -a; source .env; set +a
uv run bot.py
yay -S tg-mpv-bot-git
install -m600 /usr/share/doc/tg-mpv-bot/env.example ~/.config/tg-mpv-bot.env
$EDITOR ~/.config/tg-mpv-bot.env   # BOT_TOKEN + ALLOWED_USERS
systemctl --user enable --now tg-mpv-bot
docker pull ghcr.io/antlis/tg-mpv-bot:latest
# host networking + X11 bind mounts — see docker-compose.yml in the repo
